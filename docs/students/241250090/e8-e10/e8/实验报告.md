## 4 E8 实验内容

### 4.1 输入

`fixture()` 生成 C0 项目，包含 `main.c`、`helper.c`、`config.h`、`extra.h`、`unused.h` 与 `Makefile`。构建声明为：

```text
main.o: main.c unused.h
helper.o: helper.c
```

`main.c` 实际包含 `config.h`，`unused.h` 未被读取。

### 4.2 步骤与命令

```bash
source "$E8_PACK/classroom_helpers.sh"
lab_ready
lab_new_run e8 A
```

按手册第 1 至 7 步执行：`fixture()` 创建样例；`scan()` 建立 GCC 投影基线；`buildchecker()` 执行真实 clean build 与 `strace` 跟踪；读取 `actual-graph.json` 并投影到两个对象目标；`scan(project, baseline)` 验证未变化输入复用；最后写入 `结论.txt`。每一步的容器输出与退出码保存在 `evidence/steps/`。

### 4.3 预期与实际

| 检查项 | 预期 | 实际 |
|---|---|---|
